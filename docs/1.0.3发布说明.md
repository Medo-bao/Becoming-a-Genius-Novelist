# 1.0.3 发布说明

发布日期为 2026-11-07。

## 更新内容

- Codex 和 ZCode 使用原生子代理与共享 CLI，绑定和复用按各自的运行时隔离。DSH 适配 0.2.2-rc.1 的工具能力探测、预设作用域和文件操作守卫。
- 合并收件、诊断和下一单准备，同批岗位可复用仍可用的代理及有效阅读材料。
- 默认每单连续写作 2–3 章。逐章保存正文、两更和出章状态，再交接下一章材料。
- 复核问题先分流。明确的排版、标点和个别错字走受限微修，实质返修由独立复核确认。
- 暂停保留已提交章节和可恢复的复核结果。恢复后重新核对授权和依据，可重派中断任务尚未提交的章节。
- 支持按采用表处理外部稿件版本撞号，并兼容 Windows 跨行返修补丁。

## 从源码安装

运行需要 Node.js 18 或更新版本。下载源码归档并解压，或检出标签 v1.0.3。

- Codex 在源码根目录执行下面两条命令。
- DSH 在插件管理器选择本地源码目录，安装后在新会话选择「我要成为天才小说作家」。
- ZCode 在 Plugin Marketplace 添加源码根目录，安装插件后在新聊天选用该技能。详见 [ZCode 适配](ZCode适配.md)。

```powershell
codex plugin marketplace add "<源码根目录的绝对路径>"
codex plugin add tiancai-novel@tiancai-novel-local
```

使用方式见[使用说明](使用说明.md)。
