# 1.0.2

发布日期：2026-10-28。

## 更新内容

- 优化复核材料组织，按章整合完整正文与依据，共享资料一次读取；保留逐章有效通过结论，只复验未通过或实际受影响的章节。
- 复核报告保存时立即预检字段、评分和连续引文；格式错误由原复核代理修正同一报告，最多回修3次，减少重新派单和整批重读。
- DSH在当前会话明确授权后，成功收件自动启动下一岗位；重复收件不会重复派单，暂停、中止和只读状态会停止自动续作。
- finish按既有复审间隔批量补登记现稿记录，准确计量并拒绝夹带正文补丁；恢复制作时先保存最新范围，避免继续旧目标。
- 新增机械排版与实际文本差异反馈，减少整章重抄；纠正固定4000字占位、自设底本95%门槛和缺乏作者依据的格式阻塞，补充前章时间转场定位与首稿集中回读。
- 修复DSH阅读回执把文件末尾空行误当必读内容的问题，并同步阅读材料与正文视图的有效行数。
- 完善Codex原生与项目级CLI定位、首次子代理绑定、空闲代理唤醒、持续等待和收件续派；同一代理不能同时绑定两张未收件任务，收件后仍可复用。
- 修复跨Python/Node时间戳精度误报，精简调度回包，区分无关历史提示与当前依赖问题，保持当前章节和直接依赖的有效性检查。

六岗位分工、文笔与复核身份独立、既定复审间隔及TXT、Word/DOCX、EPUB和Markdown交付继续保留。Codex仅在明确调用`$tiancai-novel`、点选本插件或明确指定使用本插件时启动。

## 安装与升级

DSH下载`firefly-harness-dsh-tiancai-novel-1.0.2.tgz`，通过插件管理器安装；同版本升级也需重启DSH并使用新worker。

Codex下载`tiancai-novel-1.0.2.zip`，解压后注册本地插件目录：

```powershell
codex plugin marketplace add "<解压后的插件绝对目录>"
codex plugin add tiancai-novel@tiancai-novel-local
```

安装后新开聊天，再明确调用本插件。运行需要Node.js 18或更新版本，无新增第三方运行依赖。
