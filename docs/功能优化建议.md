# 功能迭代状态

当前流程以自动诊断、单主会话和六岗位子代理为中心，详见[迭代记录](迭代记录.md)。首次缺项询问、任务隔离、队长收集、独立复核、上游依赖失效与真实交付文件核对已纳入制作协议。

后续应根据真实使用继续改进：

1. 在更多原创和改编项目中验证上下文材料的相关程度，调节人物、事实与经验筛选，优先减少漏读而非扩大整书加载。
2. 用真实作者的返修选择改善文风复核提示，保留具体引文与场景判断，避免把机械特征当文学质量分数。
3. 需要投稿排版时，再增加Word版式预设；当前提供可编辑文字、章节导航、分页和页码。
4. ZCode专门适配仍留待后续；沿用当前核心与数据，核对其实际技能发现方式和宿主运行流程。

当前实现保持零第三方运行时依赖；子代理由DSH/Codex宿主提供，无需额外数据库或后台服务。后续优先积累真实岗位结果与作者裁决，改善派单材料的相关性、返修根因和文风判断，不增加无依据的全书重复扫描。
