## 结果协议

返修文笔提交：

```json
{
  "patches": [{"before": "当前稿中唯一原句", "after": "修改后的原句"}],
  "notes": "实际修订和后章提醒",
  "experience": "本次可复用经验",
  "exitState": {"位置": "实际位置"}
}
```

`text`与`patches`互斥；需要整章重写时用`text`加`rewriteReason`。草稿或结果写入任务目录后，DSH调用`novel_draft {"file_path":"实际文件"}`；Codex调用`novel draft-check <项目> --task ID --file 实际文件`。两者只计量任务产物，不运行工程测试。

复核`resolutions`中的解决项：

```json
{"id":"I1","status":"resolved","resolution":"独立读回新版，已落实修法","evidence":{"path":"当前章稿路径","quote":"修复后的真实原句"}}
```

尚未解决保留open；issues只记新发现。关闭必须覆盖问题影响范围并引用当前稿；缺失/虚假证据拒绝关账，作者裁决项不可由复核代关。red始终阻塞，yellow默认阻塞；info或有理由的blocking:false建议不触发返修。已提交修订先复验；未通过再修，连续未通过仍遵守熔断。
