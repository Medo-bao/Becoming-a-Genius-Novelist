## 结果协议

返修文笔提交：

```json
{
  "patches": [{"before": "当前稿中唯一原句", "after": "修改后的原句"}],
  "notes": "实际修订和后章提醒",
  "experience": "本次可复用经验",
  "exitState": {"位置": "实际位置"}
}
```

`text`与`patches`互斥；需要整章重写时用`text`加`rewriteReason`。草稿或结果写入任务目录后，DSH调用`novel_draft {"file_path":"实际文件"}`；Codex调用`novel draft-check <项目> --task ID --file 实际文件`。两者只计量任务产物，不运行工程测试。

复核`resolutions`中的解决项：

```json
{"id":"I1","status":"resolved","resolution":"独立读回新版，已落实修法","evidence":{"path":"当前章稿路径","quote":"修复后的真实原句"}}
```

尚未解决保留open；issues只记新发现。关闭必须覆盖问题影响范围并引用当前稿；缺失/虚假证据拒绝关账，作者裁决项不可由复核代关。red始终阻塞，yellow默认阻塞；info或有理由的blocking:false建议不触发返修。已提交修订先复验；未通过再修，连续未通过仍遵守熔断。

## 集中验证

原有五个集成场景于本轮集中5/5通过，约32.6秒，独立测试场景数不变。覆盖：

- 局部补丁只修改命中原句，原稿及其他文字保留，CLI精确计量；提交后diagnosis转review。
- 未关闭阻塞问题不能假通过；不存在的新证据不能关闭；有效独立复核自动关闭并留身份与历史。
- DSH绑定任务计量、当前稿只读、输入完整阅读、独立代理提交与精简回执；非阻塞建议通过后不再循环返修。
- 整册切片排除无关章节，同批相同长文本共享路径；GB18030底本、TXT/Word/EPUB/Markdown交付检查保留。
- 1.0.1 warn报告接回、错误参数拒绝、授权/暂停/尾批/熔断/校准及原有边界保持。

这些是代码与宿主夹具验证，没有调用在线DSH模型，不据此承诺固定写作耗时或文学质量。当前按统一版本要求安装本轮1.0.1 bundle并重启DSH，让新worker加载新工具和协议；已失败的旧任务保留产物，由新任务核对真实当前稿后继续。原先排除的“先创建会话再切换小说预设”已补充切换后的实例级工具隔离，但不做完整会话迁移。
