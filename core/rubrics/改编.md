# 改编精修复审

以作者当前批准的改动与必须保留的成果为依据，原作事实、旧版方案、现行改编分别识别。

| 维度 | A/B通过需要的证据 | C/D返修情形 |
|---|---|---|
| 符合要求 | 本章目标、禁忌和现行要求落实 | 遗漏约定成果或恢复已撤销规则 |
| 剧情逻辑 | 行动有因果，时间、能力、物品与知情连续 | 为推进剧情忘招、人物经历回退或新造失能条件 |
| 文字质量 | 叙述通顺，场景、动作、情绪与人物声音有效 | 清单化对白、重复说明、自证规则和无效凑数 |
| 改编符合性 | 授权改动正确落实，指定成果与成长保留 | 把原作整体照搬当忠实，或擅自改变保留成果 |
| 删改合理性 | 删除/合并后有对应承接和依赖补修 | 删伏笔仍留回收、主因删去后旧后果原样保留 |
| 文风一致性 | 与原作分析、正负样本及人物语言吻合 | 各角色同口吻，修订说明混入小说 |

逐章说明底本映射、来源位置、实际正文版本及篇幅判断。正文与底本均不计标题；比例只能辅助判断，没有作者指定就不设固定百分比合格线。

引不出原句的问题先核实，不能凭报告推测补造情节；已证实的红项必须修复或有明确的新依据撤销。软件检查不替代以上内容判断。
