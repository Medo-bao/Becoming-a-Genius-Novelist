# 评分表 · 原创

每项 A/B/C/D，**B 为通过线**；任一 🔴 或任一项 C 以下即整批不通过。

## 1. 符合要求

| 级别 | 标准 |
|---|---|
| A | 细纲目标全部完成，无违背注意事项，字数绿区 |
| B | 目标完成，个别次要项未落实但不影响阅读 |
| C | 有一个细纲目标未完成 |
| D | 主线目标缺失，或违背禁写项 |

## 2. 剧情逻辑

| 级别 | 标准 |
|---|---|
| A | 每个选择都有前因后果，时间线自洽，没有巧合推动 |
| B | 因果清楚，个别转折略快但能自圆 |
| C | 有明显「为了推进而推进」 |
| D | 断链、人物动机不成立、时间线冲突 |

## 3. 文字质量

| 级别 | 标准 |
|---|---|
| A | 可直接成书：无套话、对话遮名可辨、描写服务人物 |
| B | 通顺可读，少量水词或说明句 |
| C | 水词成段、情绪直给、视角漂移 |
| D | 读不下去：病句、复制感、AI 腔 |

## 4. 节奏与钩子

| 级别 | 标准 |
|---|---|
| A | 每章有推进，章末钩子有效且不重复 |
| B | 推进清楚，个别章偏平 |
| C | 连续两章无效推进 |
| D | 整批没有钩子 / 全用同一句式 |

## 常见 🔴 清单（直接打回）

- 主角在没有信息的情况下做出正确判断（上帝视角）
- 战力/资源突然超限
- 已死亡/已离开的角色出场
- 字数越红区且无说明
- 章末钩子与细纲不符且更弱
