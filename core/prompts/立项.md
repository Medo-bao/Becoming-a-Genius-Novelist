# 提示词 · 立项（G0）

把下面这段直接发给智能体（或作为开场）：

```
按《我要成为天才小说作家》开工。

渠道：原创 / 改编精修（选一个）

请先核对现有用户指示和资料，把已有答案填好；下面只问缺失且影响方向的项，一次问完：
1. 题材 + 一句话核心梗概
2. 目标读者与阅读场景
3. 篇幅：起止章号或章数；固定每章汉字目标，或明确按各底本章篇幅制作
4. 风格与对标：三个参照 + 想要什么 + 不要什么
5. 渠道（若改编：底本路径、章节数、总字数、授权说明）
6. 硬约束与执行参数：视角、时态、禁写项，以及每几章复审

队长派主编子代理整理立项资料，缺失参数等我回答；已有明确答案不重复确认。队长通过 config 记录参数与来源，再依据实际立项资料用 gate 登记，不手改生成状态。
```

## 队长收到的处理

1. doctor 检查四类关键参数的明确来源，先从现有材料提取；确实缺失才集中询问，不替用户编。
2. 改编先识别底本、章号和字数，沿用已有改动边界，缺少的作者取舍一并问。
3. 得到必要答案后派六岗位中相关子代理完成规划，队长只登记/收集。无需逐阶段重复索取已给授权。
