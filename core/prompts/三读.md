# 提示词 · 三读（每章动笔前）

```
【三读回执 · 第NNN章】
1. 本章目标：<抄细纲第一条，一句话>
2. 篇幅政策：<prepare 提供的固定字数目标，或本章映射底本篇幅及作者边界>
3. 本章禁忌：<07-注意事项 里本章相关条目；没有就写「无新增」>
4. 本章出场角色与语言基因：<角色ID + 一句特征>
5. 本章要动到的伏笔：埋 F-___ / 收 F-___
```

## 规则

- 三读没读完，不许写正文。
- 细纲不存在时，交回队长派剧情子代理补齐；文笔不擅自补剧情后代写。
- 回执要短：每项一行，别把细纲全文抄一遍。
- 文笔子代理只在任务目录交正文与回执，由队长 collect 提交。
