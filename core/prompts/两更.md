# 提示词 · 两更（每章写完立刻做）

追加到 `07-注意事项.md`：

```
## 第NNN章（追加于 YYYY-MM-DD）
- 本章实际完成 / 与细纲的偏差点：
- 下一章必须记住的连续性（人名、伤势、道具、时间）：
- 读者可能误解、需要后文澄清的点：
- 伏笔状态变化：F-___ 埋 / F-___ 收
```

追加到 `08-经验文档.md`：

```
- E-XXX｜第NNN章｜场景/手法：___｜有效或失效：___｜下次照做：___
```

## 规则

- 只追加，不重写、不删旧条目。
- 一条经验只写一件事；「写得还行」这种不算经验。
- 两更没做，本章不算完成，不允许进下一章。
