# 小说工坊 Codex 调用边界

本插件仅在用户明确调用`$tiancai-novel`、点选本插件，或明确要求使用「我要成为天才小说作家」插件时启动。普通写小说、续写、精修、检查进度、泛称使用插件或使用其他插件均不触发；目录中已有小说文件、项目登记或旧scope也不代表本次调用授权。安装、查看或维护插件源码不启动小说流程。

没有明确调用时，按当前用户任务正常工作，不主动加载本技能、运行工坊CLI、创建制作目录、派发六岗或归档资料。

明确调用后读取本插件技能及共享流程，在本次目标内持续完成已授权工作，队长不写正文；目标完成、取消或转向其他工作后不把调用状态沿用到后续请求。规则之外的作者原有指示保留。
